# 1.项目搭建

## 1.Electron forge

### 1.1 简介

- 官网地址：[https://www.electronforge.io/](https://www.electronforge.io/ "https://www.electronforge.io/")

Electron官方的脚手架工具，一体化解决方案：

- 简化开发流程，现代技术栈，一键运行
- 复杂流程简单化
  - 应用打包
  - 应用签名
  - 多平台应用打包
  - 自动更新
- 易于扩展，有插件系统

### 1.2 安装

安装命令行工具：

```bash 
npm install --save-dev @electron-forge/cli
```


创建 electron-forge 项目：

```bash 
npm init electron-app@latest my-app -- --template=vite  #my-app:项目名
#或
npm create electron-app@latest my-app -- --template=vite #my-app:项目名
#或
pnpm create electron-app my-app --template=vite  #my-app:项目名  
```


`--template`参数可指定模板，目前支持4种模板：

- `webpack`
- `webpack-typescript`
- `vite`
- `vite-typescript`

运行项目：

```bash 
pnpm run start
```


## 2.结合vue3

- 官方地址：[Vue 3 | Electron Forge](https://www.electronforge.io/guides/framework-integration/vue-3 "Vue 3 | Electron Forge")

### 2.1 安装依赖

```javascript 
npm install vue
npm install --save-dev @vitejs/plugin-vue
```


### 2.2 测试

`vite.renderer.config.ts`引入vue支持

```typescript 
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

// https://vitejs.dev/config
export default defineConfig((env) => {
    return {
        plugins: [
            vue()
        ]
    }
});
```


新建 `src/App.vue`

```javascript 
<template>
    <h1> Hello World!</h1>
    <p>Welcome to you Electron app.</p>
</template>

<script setuo lang="ts">
    console.log('Hello World!')
</script>
```


修改 s`rc/renderer.ts` 引入 vue app

```typescript 
import { createApp} from 'vue'
import App from './App.vue'
import './index.css';

console.log('👋 This message is being logged by "renderer.ts", included via Vite');

createApp(App).mount('#app')
```


修改 index.html 主页展示

```html 
<!DOCTYPE html>
<html>
  <head>
    <meta charset="UTF-8" />
    <title>Hello World!</title>

  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/renderer.ts"></script>
  </body>
</html>

```


运行项目

```bash 
pnpm run start
```


## 3.Tailwindcss &#x20;

### 3.1 简介 &#x20;

**Tailwind CSS** 是一款高效的实用类 CSS 框架，通过预定义的类名快速构建响应式界面，避免手写大量 CSS 代码。其核心特点是“功能优先”，将常用的 CSS 属性（如布局、颜色、尺寸等）封装为类名，开发者可直接在 HTML 中组合类名实现样式效果，同时支持自定义主题和扩展功能。适合快速开发原型或构建大型项目，文档详尽且社区活跃（官网：[https://tailwindcss.com/](https://tailwindcss.com/ "https://tailwindcss.com/")）。 &#x20;

### 3.2 安装 &#x20;

1. **环境要求**：需先安装 Node.js（建议 v14+）和 npm/yarn。 &#x20;
2. **安装命令**（以 pnpm 为例）： &#x20;
   ```bash 
   pnpm install -D tailwindcss@3.4.17 postcss autoprefixer  # 安装 Tailwind 及依赖
   npx tailwindcss init -p  # 生成配置文件并关联 postcss
   ```

3. **配置文件（****`tailwind.config.js`****）**： &#x20;

   生成后需在 `content` 字段中指定 HTML 和组件文件路径，例如： &#x20;
   ```javascript 
   export default {
     content: [
       "./index.html",
       "./src/**/*.{vue,js,ts,jsx,tsx}",
     ],
     theme: {
       extend: {
         // 自定义主题（如颜色、字体等）
       },
     },
     plugins: [],
   }
   ```

4. **引入样式**：在项目主 CSS 文件（`index.css`）中添加： &#x20;
   ```css 
   @tailwind base;    /* 基础样式，如重置样式 */
   @tailwind components; /* 可复用组件样式 */
   @tailwind utilities; /* 实用类样式 */
   ```

5. **应用**：可直接在 `App.vue`中使用：
   ```react jsx 
   <template>
       <h1 class="text-3xl font-bold bg-sky-300"> Hello World!</h1>
       <p>Welcome to you Electron app.</p>
   </template>

   <script setuo lang="ts">
       console.log('Hello World!')
   </script>
   ```


### 3.3 使用 &#x20;

#### （1）布局 &#x20;

- **Flex 布局**：通过类名快速定义容器和子元素的排列方式。 &#x20;
  - 容器类：`flex`（开启 flex）、`flex-row`（水平排列）、`flex-col`（垂直排列）、`justify-center`（水平居中）、`items-center`（垂直居中）等。 &#x20;
  - 示例：`<div class="flex flex-col items-center justify-between">...</div>`。 &#x20;
- **Grid 布局**：用于网格布局，类名如 `grid`（开启网格）、`grid-cols-2`（2 列）、`grid-rows-3`（3 行）、`gap-4`（间距）等。 &#x20;
- **响应式布局**：结合断点前缀（如 `md:`、`lg:`）实现不同屏幕尺寸的布局变化，例：`md:flex-row`（中等屏幕以上水平排列）。 &#x20;
- **参考资料**： &#x20;
  - [Tailwind Flex 文档](https://tailwindcss.com/docs/flex "Tailwind Flex 文档") &#x20;
  - [CSS-Tricks Flex 指南](https://css-tricks.com/snippets/css/a-guide-to-flexbox/ "CSS-Tricks Flex 指南") &#x20;

#### （2）颜色 &#x20;

- **基础用法**：通过 `text-[颜色]` 和 `bg-[颜色]` 类名设置文本和背景色，如 `text-red-500`（红色文本）、`bg-blue-100`（浅蓝色背景）。 &#x20;
- **颜色层次**：Tailwind 预设多种颜色层级（如 `-50` 到 `-900`），数值越小颜色越浅，例：`bg-green-50`（淡绿色）、`text-purple-800`（深紫色）。 &#x20;
- **自定义颜色**：在 `tailwind.config.js` 的 `theme.extend` 中添加： &#x20;
  ```javascript 
  theme: {
    extend: {
      colors: {
        primary: '#3B82F6',  // 自定义主色
        secondary: '#10B981', // 自定义辅助色
      },
    },
  }
  ```

- **透明色**：使用 `opacity-[数值]`（如 `opacity-50` 半透明）或 `bg-[颜色]-[层级]/[透明度]`，例：`bg-red-500/30`（30% 透明红色背景）。 &#x20;
- **参考资料**：[Tailwind 颜色定制文档](https://tailwindcss.com/docs/customizing-colors "Tailwind 颜色定制文档") &#x20;

#### （3）尺寸 &#x20;

- **固定尺寸**： &#x20;
  - 单位为 `rem`（1 单位 = 0.25rem = 4px），类名如 `w-4`（宽度 1rem/4px）、`h-8`（高度 2rem/8px）、`p-4`（内边距 1rem）、`m-6`（外边距 1.5rem）。 &#x20;
  - 特殊值：`w-full`（100% 宽度）、`h-screen`（屏幕高度）、`max-w-md`（最大宽度为中等尺寸）。 &#x20;
- **比例尺寸**： &#x20;
  - 宽高比例类：`aspect-square`（1:1）、`aspect-video`（16:9），或自定义 `aspect-[width/height]`，例：`aspect-[4/3]`（4:3 比例）。 &#x20;
- **响应式尺寸**：结合断点前缀，如 `md:w-32`（中等屏幕以上宽度 8rem）。 &#x20;
- **任意尺寸**：使用 `w-[100px]`、`h-[50%]`、`max-h-[200px]` 等格式直接定义数值和单位。 &#x20;
- **参考资料**：[Tailwind 尺寸文档](https://tailwindcss.com/docs/width "Tailwind 尺寸文档") &#x20;

#### （4）状态 &#x20;

- **伪类状态**： &#x20;
  - `:hover`：类名前缀 `hover:`，例：`hover:bg-red-100`（鼠标悬停时背景变红）。 &#x20;
  - `:focus`：`focus:outline-none focus:ring-2 focus:ring-blue-500`（聚焦时移除轮廓并添加蓝色边框）。 &#x20;
  - `:active`：`active:scale-95`（点击时缩小 5%）。 &#x20;
- **响应式状态**：结合断点和状态，如 `md:hover:bg-green-500`（中等屏幕以上悬停变绿色）。 &#x20;
- **伪元素状态**： &#x20;
  - `::before` 和 `::after`：通过 `before:content-[''] before:bg-black` 等类名添加伪元素样式。 &#x20;
  - `::placeholder`：`placeholder:italic placeholder:text-gray-400`（占位文本斜体+灰色）。 &#x20;
- **媒体查询状态**： &#x20;
  - 暗黑模式：`dark:bg-gray-900`（暗黑模式下背景为深灰）。 &#x20;
  - 响应式断点：`md:px-8`（中等屏幕以上左右内边距 2rem）。 &#x20;
- **属性选择器**：如 `[open]:bg-yellow-100`（元素存在 `open` 属性时背景变黄）。 &#x20;
- **参考资料**： &#x20;
  - [Tailwind 状态文档](https://tailwindcss.com/docs/hover-focus-and-other-states "Tailwind 状态文档") &#x20;
  - [响应式设计文档](https://tailwindcss.com/docs/responsive-design "响应式设计文档")

## 4. Iconify Design &#x20;

### 4.1 简介 &#x20;

**Iconify Design** 是一个开源的图标管理解决方案，致力于为开发者提供便捷的图标集成与管理方式。其核心优势包括： &#x20;

- **多图标集整合**：汇聚全球流行图标库（如 Font Awesome、Material Icons、Ionicons 等），提供统一调用接口，避免多库切换的繁琐。 &#x20;
- **海量图标资源**：拥有超过 200,000 个开源矢量图标，覆盖各类场景（社交、工具、商业等），满足多样化设计需求。 &#x20;
- **统一框架与组件化**：提供标准化的图标组件和调用方式，支持主流前端框架（如 Vue、React、Angular 等），简化图标集成流程。 &#x20;
- **开源与许可证**：项目遵循 MIT 许可证（大部分），部分旧包采用 Apache 2.0 或 GPL 2.0 许可证，商业使用友好。 &#x20;
- **官网与资源**： &#x20;
  - 官网：[https://iconify.design/](https://iconify.design/ "https://iconify.design/") &#x20;
  - 图标浏览：[https://icon-sets.iconify.design/](https://icon-sets.iconify.design/ "https://icon-sets.iconify.design/") &#x20;

### 4.2 安装 &#x20;

1. **环境要求**：需先安装 Node.js 和 npm/yarn，且项目已集成 Vue（2.x 或 3.x）。 &#x20;
2. **安装命令**（以 npm 为例）： &#x20;
   ```bash 
   npm install --save-dev @iconify/vue  # 安装 Vue 图标组件
   ```

   *说明*：`--save-dev` 表示安装为开发依赖，生产环境打包时不会包含多余代码。 &#x20;

### 4.3 使用（Vue 方式） &#x20;

#### （1）基础用法 &#x20;

1. **全局注册组件**（推荐方式，避免重复引入）： &#x20;

   在 Vue 主文件（如 `main.js` 或 `main.ts`）中： &#x20;
   ```javascript 
   import { createApp } from 'vue'
   import { Icon } from '@iconify/vue'

   const app = createApp(App)
   app.component('Icon', Icon)  // 全局注册为 <Icon> 组件
   app.mount('#app')
   ```

2. **在模板中使用**： &#x20;
   ```vue 
   <template>
     <div>
       <!-- 语法：<Icon icon="图标集:图标名称" /> -->
       <Icon icon="mdi-light:home" />  <!-- Material Design 浅色风格的首页图标 -->
       <Icon icon="fa-solid:user" class="text-blue-500" />  <!-- Font Awesome 实心用户图标，蓝色 -->
       <Icon icon="ion:logo-vue" width="32" height="32" />  <!-- Ionicons 的 Vue 图标，32x32 尺寸 -->
     </div>
   </template>
   ```


#### （2）图标集与名称格式 &#x20;

- **图标集命名规则**：`图标集名称:图标名称`，例如： &#x20;
  - `mdi-light:home`：`mdi-light` 是 Material Design 浅色图标集，`home` 是图标名。 &#x20;
  - `fa-brands:github`：`fa-brands` 是 Font Awesome 品牌图标集，`github` 是 GitHub 图标。 &#x20;
- **查询图标名称**：通过 [图标浏览页面](https://icon-sets.iconify.design/ "图标浏览页面") 搜索目标图标，点击即可获取完整名称。 &#x20;

#### （3）组件属性与样式 &#x20;

- **基础属性**： &#x20;
  - `icon`：必选，指定图标集和名称。 &#x20;
  - `width`/`height`：设置图标宽高（单位像素，如 `width="24"`）。 &#x20;
  - `flip`：翻转图标，值为 `horizontal`（水平）或 `vertical`（垂直），例：`flip="horizontal"`。 &#x20;
  - `rotate`：旋转角度（度数，如 `rotate="90"`）。 &#x20;
- **样式定制**： &#x20;
  - 通过 class 类名设置颜色、大小等，例：`class="text-red-500 text-2xl"`（红色+2倍字体大小）。 &#x20;
  - 直接设置内联样式：`style="color: #3B82F6; margin-right: 8px;"`。 &#x20;

#### （4）按需加载与性能优化 &#x20;

- **按需引入**（适合大型项目）： &#x20;

  若项目仅使用少量图标，可避免全局注册，改为按需引入： &#x20;
  ```vue 
  <template>
    <Icon :icon="homeIcon" />
  </template>

  <script setup lang='ts'>
  import { Icon } from '@iconify/vue'

  </script>
  ```

- **图标预加载**：在项目初始化时预加载常用图标，提升首次渲染速度（需配合 Iconify 工具链）。 &#x20;

## 5. Radix Vue &#x20;

### 5.1 简介 &#x20;

**Radix Vue** 是基于 [Radix UI](https://radix-ui.com/ "Radix UI") 构建的 Vue 组件库，专注于提供**可访问性强、功能完备且高度可定制**的基础UI组件。其核心特点包括： &#x20;

- **无障碍设计优先**：所有组件均遵循 WCAG 标准，内置键盘导航、ARIA 标签等无障碍特性，确保残障用户可正常使用。 &#x20;
- **无样式架构**：组件仅提供功能逻辑和基础结构，不包含预设样式，允许开发者完全自定义外观，适配各种设计体系。 &#x20;
- **组件生态丰富**：涵盖按钮、模态框、下拉菜单、日期选择器等高频交互组件，支持 Vue 2 和 Vue 3。 &#x20;
- **与 Tailwind CSS 兼容**：天然适配 Tailwind CSS，可通过实用类快速美化组件，也可结合自定义 CSS 或其他样式方案。 &#x20;

### 5.2 使用方法 &#x20;

#### （1）安装与配置 &#x20;

1. **安装依赖**（以 npm 为例）： &#x20;
   ```bash 
   npm install @radix-vue/[组件包]  # 按需安装，如按钮组件：
   npm install @radix-vue/button  # 或安装完整库（若项目需求全面）
   ```

   *提示*：Radix Vue 采用模块化设计，建议按需安装以减小包体积。 &#x20;
2. **引入组件**（以按钮为例）： &#x20;
   ```vue 
   <template>
     <Button>点击我</Button>
   </template>

   <script>
   import { Button } from '@radix-vue/button'
   export default {
     components: { Button }
   }
   </script>
   ```


#### （2）基础组件使用示例 &#x20;

1. **按钮组件（Button）**： &#x20;
   ```vue 
   <!-- 基础用法 -->
   <Button class="bg-blue-500 text-white px-4 py-2 rounded hover:bg-blue-600">
     主按钮
   </Button>

   <!-- 带图标按钮（结合 Iconify） -->
   <Button class="flex items-center space-x-2">
     <Icon icon="mdi-light:home" />
     <span>首页</span>
   </Button>
   ```

2. **模态框组件（Dialog）**： &#x20;
   ```vue 
   <template>
     <div>
       <Button @click="isOpen = true">打开模态框</Button>
       <Dialog v-model="isOpen" class="w-1/2 max-w-md mx-auto">
         <Dialog.Title>提示</Dialog.Title>
         <Dialog.Content class="p-4">这是一个模态框内容</Dialog.Content>
         <Dialog.Action>
           <Button @click="isOpen = false">关闭</Button>
         </Dialog.Action>
       </Dialog>
     </div>
   </template>

   <script>
   import { Dialog, Button } from '@radix-vue/dialog'
   export default {
     components: { Dialog, DialogTitle: Dialog.Title, /* 解构组件 */ },
     data() {
       return { isOpen: false }
     }
   }
   </script>
   ```


#### （3）样式定制与扩展 &#x20;

- **结合 Tailwind CSS**：通过类名直接定义样式，例： &#x20;
  ```vue 
  <Button class="bg-red-500 hover:bg-red-600 text-white font-medium rounded-lg shadow-md px-6 py-3 transition-all duration-200">
    自定义按钮
  </Button>
  ```

- **自定义 CSS**：通过组件的 `class` 或 `style` 属性添加自定义样式，或在全局样式中覆盖： &#x20;
  ```css 
  /* 全局样式中修改按钮默认样式 */
  .radix-button {
    font-family: 'Inter', sans-serif;
    border-radius: 4px;
  }
  ```

- **主题配置**：在 Vue 项目中通过 `provide/inject` 机制传递主题配置（需参考 [官方文档](https://radix-vue.com/next/docs/guides/theme-configuration "官方文档")）。 &#x20;

#### （4）无障碍特性与交互逻辑 &#x20;

- **键盘导航**：组件内置 `Tab` 键焦点管理，如模态框自动捕获焦点并阻止背景滚动。 &#x20;
- **ARIA 属性**：组件自动生成 `aria-label`、`aria-expanded` 等属性，可通过 `aria-*` 自定义属性扩展。 &#x20;
- **事件处理**：组件暴露标准事件（如 `click`、`focus`），支持自定义交互逻辑： &#x20;
  ```vue 
  <Button @keydown.enter="handleSubmit">提交</Button>
  ```


#### （5）响应式布局与 Grid 结合 &#x20;

- **使用 Tailwind Grid**：通过 Tailwind 的网格类名快速排列组件，例： &#x20;
  ```vue 
  <div class="grid grid-cols-1 md:grid-cols-2 gap-4">
    <ComponentA />
    <ComponentB />
  </div>
  ```

- **原生 CSS Grid**：结合 [CSS-Tricks Grid 教程](https://css-tricks.com/snippets/css/complete-guide-grid/ "CSS-Tricks Grid 教程") 实现复杂布局： &#x20;
  ```css 
  .grid-container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 1rem;
  }
  ```


#### （6）参考资料 &#x20;

- **官方文档**：[Radix Vue 文档](https://radix-vue.com/next/ "Radix Vue 文档")（含组件API、示例和最佳实践）。 &#x20;
- **组件库浏览**：[Radix UI 组件示例](https://radix-ui.com/primitives/components "Radix UI 组件示例")（可查看各组件交互效果）。 &#x20;
- **无障碍指南**：[WCAG 标准解读](https://www.w3.org/TR/WCAG21/ "WCAG 标准解读")（了解组件无障碍设计的底层逻辑）。
