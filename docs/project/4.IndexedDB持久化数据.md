# 4.IndexedDB持久化数据

## 1. 数据结构

### 1.1 数据结构特点

- **多数据结构关联**：存在多个相互关联的数据结构，数据间存在复杂的关系网络。
- **大规模数据**：涉及的数据量较大，需要高效的存储和管理方式。
- **异步操作需求**：对数据的操作需要支持异步处理，以适应复杂的业务场景和提高系统响应性能。

## 2. 方案分析

### 2.1 本地文件存储（文件或localStorage）

- **特点**：数据以文件形式存储在本地，简单易用。
- **优点**：实现和维护成本低，使用门槛低。
- **缺点**：
  - 对于大量数据或需要复杂查询的应用，性能会受到较大限制。
  - 存储容量通常较小，如LocalStorage一般为5MB，难以满足大规模数据存储需求。

### 2.2 electron-store

- **特点**：Electron官方推荐的轻量级持久性数据存储解决方案，本质是一个json文件，与本地文件存储类似。
- **优点**：
  - 支持主进程和渲染进程共享数据。
  - 拥有良好的API和文档，使用方便。
- **缺点**：仅适用于小规模数据存储，在处理大规模数据时性能可能不足。

### 2.3 SQLite

- **特点**：轻量级关系型数据库，是世界上使用最多的轻量级数据库，提供SQL查询语言支持。
- **优点**：
  - 适用于需要复杂查询和事务处理的应用场景。
  - 性能表现较好。
- **缺点**：与Electron集成相比IndexedDB需要更多的工作，操作相对复杂。

### 2.4 IndexedDB

- **特点**：基于浏览器的客户端存储技术，支持异步操作。
- **优点**：
  - 适合存储大量结构化数据，性能良好。
  - 支持索引、事务等功能，能满足复杂的数据处理需求。
- **缺点**：复杂度较高，需要处理异步编程，对开发者要求较高。

### 2.5 方案选择

选择IndexedDB的原因：

- **性能**：能够很好地处理大量结构化数据，具有出色的性能表现。
- **标准化**：作为浏览器标准，与Electron集成相对简单，兼容性好。
- **功能**：支持索引、事务等丰富功能，可满足各种复杂的数据处理需求。
- **异步操作**：其异步操作特性适合Electron中的异步编程模型，能提升系统的响应能力和用户体验。

## 3. IndexedDB

### 3.1 简介

IndexedDB是一种基于浏览器的客户端存储技术，它为Web应用提供了一种存储大量结构化数据的方法。作为浏览器的标准功能，IndexedDB支持异步操作，这使得它在处理数据时不会阻塞用户界面，保证了应用的流畅运行。它还支持索引和事务等强大功能，能够满足复杂的数据管理需求，是Web前端存储大量数据的重要解决方案之一。

### 3.2 Dexie.js简介

Dexie.js是一个针对IndexedDB的优秀封装库，在GitHub上拥有11.2k的星标，受到广大开发者的青睐。它具有以下优势：

- **简化API**：大大简化了IndexedDB原生API的使用难度，使开发者能够更轻松地操作数据库。
- **更好的异步支持**：针对异步操作进行了优化，更符合现代前端开发的异步编程模式。
- **简化数据模型**：提供了更简洁、清晰的数据模型定义方式，方便开发者进行数据结构的设计和管理。
- **性能优化**：对数据库操作的性能进行了优化，提升了数据处理的效率。

### 3.3 插入数据

使用Dexie.js插入数据的步骤如下：

（1）首先需要定义数据库和表结构，例如：

```javascript 
const db = new Dexie('MyDatabase');
db.version(1).stores({
  users: '++id, name, age', // id为自增主键，索引name和age
  messages: '++id, userId, content, timestamp'
});
```


（2）然后可以通过表的add或put方法插入数据：

```javascript 
// 插入单条数据
db.users.add({ name: '张三', age: 25 });

// 插入多条数据
db.users.bulkAdd([
  { name: '李四', age: 30 },
  { name: '王五', age: 28 }
]);

// 使用put方法，如果id存在则更新，不存在则插入
db.users.put({ id: 1, name: '张三修改后', age: 26 });
```


### 3.4 查询数据

Dexie.js提供了丰富的查询方式：

- **按主键查询**：

```javascript 
// 查询id为1的用户
db.users.get(1).then(user => {
  console.log(user);
});
```


- **使用where条件查询**：

```javascript 
// 查询年龄大于25的用户
db.users.where('age').above(25).toArray().then(users => {
  console.log(users);
});

// 查询姓名包含"张"的用户
db.users.where('name').startsWith('张').toArray().then(users => {
  console.log(users);
});
```


- **使用复合条件查询**：

```javascript 
// 查询年龄在25到30之间且姓名包含"张"的用户
db.users.where(x => x.age >= 25 && x.age <= 30 && x.name.includes('张')).toArray().then(users => {
  console.log(users);
});
```


- **使用索引查询**：

如果在定义表结构时设置了索引，就可以通过索引进行高效查询，例如：

```javascript 
// 按年龄升序查询所有用户
db.users.orderBy('age').toArray().then(users => {
  console.log(users);
});
```


### 3.5 更新数据

更新数据的方法如下：

```javascript 
// 使用update方法更新数据，参数为查询条件和更新内容
db.users.where('id').equals(1).update({ age: 27 }).then(() => {
  console.log('更新成功');
});

// 也可以先获取数据，修改后再使用put方法更新
db.users.get(1).then(user => {
  if (user) {
    user.name = '张三再次修改';
    return db.users.put(user);
  }
}).then(() => {
  console.log('更新成功');
});
```


### 3.6 删除数据

删除数据的操作如下：

```javascript 
// 删除id为1的用户
db.users.delete(1).then(() => {
  console.log('删除成功');
});

// 删除年龄大于30的用户
db.users.where('age').above(30).delete().then(() => {
  console.log('删除成功');
});

// 删除所有数据
db.users.clear().then(() => {
  console.log('所有用户数据已删除');
});
```
