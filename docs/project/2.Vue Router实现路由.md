# 2.Vue Router 实现路由

## 1.Vue Router 简介 &#x20;

**Vue Router** 是 Vue.js 官方路由管理器，用于构建单页应用（SPA）的路由系统，支持动态路由匹配、嵌套路由、路由守卫等功能。官网：[https://router.vuejs.org/](https://router.vuejs.org/ "https://router.vuejs.org/") &#x20;

## 2.安装与配置 &#x20;

1. **安装命令**（Vue 3 对应 v4 版本）： &#x20;
   ```bash 
   npm install vue-router@4
   ```

2. **基本配置示例**（`src/router/index.js`）： &#x20;
   ```javascript 
   import { createRouter, createWebHistory } from 'vue-router'
   import Home from '@/views/Home.vue'
   import About from '@/views/About.vue'

   const routes = [
     {
       path: '/',
       name: 'Home',
       component: Home
     },
     {
       path: '/about',
       name: 'About',
       component: About
     }
   ]

   const router = createRouter({
     history: createWebHistory(), // 选择路由模式
     routes
   })

   export default router
   ```

3. **在 Vue 应用中挂载**（`main.js`）： &#x20;
   ```javascript 
   import { createApp } from 'vue'
   import App from './App.vue'
   import router from './router'

   createApp(App).use(router).mount('#app')
   ```


## 3.路由模式（History Modes） &#x20;

### 3.1 Hash 模式 &#x20;

- **描述**：URL 中包含 `#` 符号，路由信息存储在 hash 部分（如 `http://example.com/#/home`）。 &#x20;
- **优点**：无需服务器配置，部署简单。 &#x20;
- **缺点**：URL 含 `#` 不够美观，可能影响 SEO。 &#x20;
- **适用场景**：快速原型开发、小型项目。 &#x20;

### 3.2 HTML5 History 模式 &#x20;

- **描述**：使用 HTML5 History API，URL 无 `#`（如 `http://example.com/home`）。 &#x20;
- **优点**：URL 更符合传统网站结构，美观且利于 SEO。 &#x20;
- **缺点**：需服务器配置（如 Nginx 重定向），避免刷新时 404。 &#x20;
- **服务器配置示例（Nginx）**： &#x20;
  ```nginx 
  location / {
    try_files $uri $uri/ /index.html;
  }
  ```


### 3.3 Memory 模式 &#x20;

- **描述**：路由状态仅在内存中管理，不同步到 URL，常用于服务端渲染（SSR）。 &#x20;
- **优点**：不影响地址栏 URL，适合特定交互场景。 &#x20;
- **缺点**：无法通过地址栏直接访问路由。 &#x20;

## 4.动态路由匹配 &#x20;

### 4.1 基本用法 &#x20;

通过 `:` 定义动态参数，例如： &#x20;

```javascript 
const routes = [
  {
    path: '/users/:id', // 匹配 /users/123 或 /users/abc
    component: UserDetail
  }
]
```


### 4.2 访问动态参数 &#x20;

在组件中通过 `$route.params` 获取： &#x20;

```vue 
<template>
  <div>用户 ID：{{ $route.params.id }}</div>
</template>
```


### 4.3 动态路由刷新策略 &#x20;

- 当参数变化（如 `users/1` → `users/2`），组件不会重新渲染，需监听参数变化： &#x20;
  ```vue 
  <script>
  export default {
    watch: {
      $route(to, from) {
        // 路由参数变化时的处理逻辑
        this.fetchUserData(to.params.id)
      }
    },
    methods: {
      fetchUserData(id) {
        // 获取用户数据
      }
    }
  }
  </script>
  ```


## 5.路由对象与导航 &#x20;

### 5.1 路由对象属性 &#x20;

- `$route.params`：动态路由参数（如 `/:id`）。 &#x20;
- `$route.query`：URL 查询参数（如 `?name=john`）。 &#x20;
- `$route.hash`：URL 哈希值（如 `#section`）。 &#x20;
- 更多属性参考：[API 文档](https://router.vuejs.org/api/#useRoute "API 文档")。 &#x20;

### 5.2 编程式导航 &#x20;

通过 `router.push` 实现页面跳转： &#x20;

```javascript 
// 字符串路径
router.push('/home')

// 对象形式
router.push({ path: '/users', query: { id: 123 } }) // 生成 /users?id=123

// 命名路由（需配置 name 属性）
router.push({ name: 'user', params: { username: 'eduardo' } }) // 生成 /user/eduardo

// 带哈希值
router.push({ path: '/about', hash: '#team' }) // 生成 /about#team
```


### 5.3 其他导航方法 &#x20;

- `router.replace()`：替换当前路由，不记录历史。 &#x20;
- `router.back()`：返回上一页，等价于 `window.history.back()`。 &#x20;

### 六、实战：抽象公共 Button 组件 &#x20;

#### 1. 需求分析 &#x20;

- **类型**：普通（默认）/ plain 风格。 &#x20;
- **颜色**：支持多种颜色（默认绿色）。 &#x20;
- **尺寸**：普通/ large / small。 &#x20;
- **状态**：禁用（disabled）、加载中（loading）。 &#x20;

#### 2. 组件实现（结合 Tailwind CSS） &#x20;

```vue 
<template>
  <button
    :class="buttonClasses"
    :disabled="isDisabled || isLoading"
    :aria-disabled="isDisabled || isLoading"
    @click="handleClick"
  >
    <!-- 加载状态显示加载图标，否则显示内容 -->
    <template v-if="isLoading">
      <span class="animate-spin mr-2">加载中...</span>
    </template>
    <template v-else>
      <slot></slot>
    </template>
  </button>
</template>

<script>
export default {
  name: 'CustomButton',
  props: {
    type: {
      type: String,
      default: 'normal',
      values: ['normal', 'plain']
    },
    color: {
      type: String,
      default: 'green',
      values: ['green', 'blue', 'red', 'yellow']
    },
    size: {
      type: String,
      default: 'medium',
      values: ['small', 'medium', 'large']
    },
    disabled: {
      type: Boolean,
      default: false
    },
    loading: {
      type: Boolean,
      default: false
    }
  },
  computed: {
    isDisabled() {
      return this.disabled || this.loading
    },
    buttonClasses() {
      // 动态生成 Tailwind 类名
      const baseClasses = 'font-medium py-2 px-4 rounded transition-all duration-200'
      const typeClasses = this.type === 'normal' 
        ? 'bg-primary text-white hover:bg-primary/90' 
        : 'bg-transparent border border-gray-300 hover:bg-gray-50'
      const colorClasses = {
        green: 'bg-green-500 hover:bg-green-600',
        blue: 'bg-blue-500 hover:bg-blue-600',
        red: 'bg-red-500 hover:bg-red-600',
        yellow: 'bg-yellow-500 hover:bg-yellow-600'
      }[this.color] || ''
      const sizeClasses = {
        small: 'text-sm py-1.5 px-3',
        medium: '',
        large: 'text-lg py-2.5 px-5'
      }[this.size]
      const disabledClasses = this.isDisabled 
        ? 'opacity-50 cursor-not-allowed' 
        : ''
      
      return `${baseClasses} ${typeClasses} ${colorClasses} ${sizeClasses} ${disabledClasses}`
    }
  },
  methods: {
    handleClick(event) {
      if (this.isLoading) event.preventDefault()
      this.$emit('click', event)
    }
  }
}
</script>
```


#### 3. 组件使用示例 &#x20;

```vue 
<template>
  <div>
    <!-- 普通绿色按钮 -->
    <CustomButton>普通按钮</CustomButton>
    
    <!-- Plain 蓝色大尺寸按钮 -->
    <CustomButton type="plain" color="blue" size="large">
      Plain 按钮
    </CustomButton>
    
    <!-- 禁用状态按钮 -->
    <CustomButton disabled>禁用按钮</CustomButton>
    
    <!-- 加载中按钮 -->
    <CustomButton :loading="true" @click="fetchData">
      加载数据
    </CustomButton>
  </div>
</template>
```


### 七、Tailwind CSS 动态类名技巧 &#x20;

1. **条件渲染类名**： &#x20;
   ```vue 
   <div :class="['bg-white', isActive ? 'border-2 border-blue-500' : 'border-gray-200']">
     <!-- 内容 -->
   </div>
   ```

2. **对象语法动态类名**： &#x20;
   ```vue 
   <div :class="{
     'bg-blue-500': isPrimary,
     'text-white': isPrimary,
     'px-6': isLarge,
     'px-4': !isLarge
   }">
     <!-- 内容 -->
   </div>
   ```

3. **在组件中动态生成类名**： &#x20;

   参考上述 Button 组件的 `buttonClasses` 计算属性，通过对象或条件语句组合类名，避免冗余代码。
