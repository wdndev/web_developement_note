# 5.Pinia状态管理

## 1. 简介 &#x20;

**Pinia** 是 Vue.js 的轻量级状态管理库，专为 Vue 3 设计，同时兼容 Vue 2。它提供了直观的 API、完整的 TypeScript 支持，并解决了传统状态管理库的一些痛点（如复杂的模板语法、模块化不足等）。

官方网站：[https://pinia.vuejs.org/zh/](https://pinia.vuejs.org/zh/ "https://pinia.vuejs.org/zh/") &#x20;

### 核心特性 &#x20;

- **直观的 API**：采用组合式 API 风格，贴近 Vue 3 的开发模式。 &#x20;
- **完整的 TypeScript 支持**：内置类型定义，无需额外配置。 &#x20;
- **模块化设计**：每个 Store 独立成模块，便于维护和复用。 &#x20;
- **轻量级**：体积小（约 1KB），性能优异。 &#x20;
- **支持 Vue 2/3**：通过不同的包兼容两种版本。 &#x20;

### 适用场景 &#x20;

- 管理跨组件共享的数据（如用户信息、主题配置）。 &#x20;
- 维护需要持久化或跨页面保存的状态（如多步骤表单）。 &#x20;
- 处理复杂的业务逻辑（如异步数据获取、状态转换）。 &#x20;

## 2. 配置 &#x20;

### 2.1 安装 &#x20;

```bash 
# Vue 3 项目
yarn add pinia
# 或
npm install pinia

# Vue 2 项目（需额外插件）
yarn add pinia vue2-pinia
# 或
npm install pinia vue2-pinia
```


### 2.2 TypeScript 支持 &#x20;

Pinia 原生支持 TypeScript，无需额外配置。在 Vue 3 项目中，可通过以下方式启用类型推导： &#x20;

（1）**全局类型声明**（推荐）： &#x20;

```typescript 
// src/store/index.ts
import { defineStore } from 'pinia'

// 定义 Store 接口
interface CounterState {
  count: number
}

// 创建 Store（自动推导类型）
export const useCounterStore = defineStore('counter', {
  state: (): CounterState => ({
    count: 0
  }),
  getters: {
    doubleCount: (state) => state.count * 2
  },
  actions: {
    increment() {
      this.count++
    }
  }
})
```


（2）**组合式 API 类型标注**： &#x20;

```typescript 
import { useStore } from 'pinia'

// 在组件中使用
const counterStore = useStore(useCounterStore)
counterStore.increment() // 类型安全的方法调用
```


## 3. 基本功能 &#x20;

### 3.1 初始化 &#x20;

#### **步骤 1：注册 Pinia 插件** &#x20;

```javascript 
// main.js (Vue 3)
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'

const app = createApp(App)
const pinia = createPinia()

app.use(pinia)
app.mount('#app')
```


#### **步骤 2：创建 Store** &#x20;

```javascript 
// src/store/counter.js
import { defineStore } from 'pinia'

export const useCounterStore = defineStore('counter', {
  // 存储状态（响应式数据）
  state: () => ({
    count: 0,
    isLoading: false
  }),
  // 计算属性（类似 Vue 的 computed）
  getters: {
    doubleCount(state) {
      return state.count * 2
    }
  },
  // 方法（类似 Vue 的 methods）
  actions: {
    increment() {
      this.count++
    },
    async fetchData() {
      this.isLoading = true
      try {
        // 模拟异步请求
        await new Promise(resolve => setTimeout(resolve, 1000))
        this.count += 5
      } finally {
        this.isLoading = false
      }
    }
  }
})
```


### 3.2 添加数据 &#x20;

#### **方式 1：直接修改 state** &#x20;

```vue 
<template>
  <button @click="increment">+1</button>
  <p>计数：{{ count }}</p>
</template>

<script setup>
import { useCounterStore } from '../store/counter'

const counterStore = useCounterStore()
const count = counterStore.count // 响应式引用
const increment = () => counterStore.count++ // 直接修改
</script>
```


#### **方式 2：调用 action** &#x20;

```vue 
<template>
  <button @click="increment">通过 action 加 1</button>
</template>

<script setup>
import { useCounterStore } from '../store/counter'

const counterStore = useCounterStore()
const increment = () => counterStore.increment() // 调用 action
</script>
```


### 3.3 查询数据 &#x20;

#### **访问 state 和 getter** &#x20;

```vue 
<template>
  <div>
    <p>原始计数：{{ counterStore.count }}</p>
    <p>双倍计数：{{ counterStore.doubleCount }}</p>
  </div>
</template>

<script setup>
import { useCounterStore } from '../store/counter'

const counterStore = useCounterStore()
</script>
```


### 3.4 更新数据 &#x20;

#### **批量更新 state** &#x20;

```javascript 
// 在组件中
counterStore.$patch({
  count: 100,
  isLoading: false
})

// 或通过函数式更新
counterStore.$patch(state => {
  state.count += 10
  state.isLoading = false
})
```


### 3.5 重置数据 &#x20;

```javascript 
// 重置为初始状态
counterStore.$reset()
```


## 4. 组件外使用 Pinia &#x20;

### 4.1 在路由守卫中使用 &#x20;

```typescript 
// router.js
import { createRouter, createWebHistory } from 'vue-router'
import { useUserStore } from '../store/user'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/dashboard', component: Dashboard, meta: { requiresAuth: true } }
  ]
})

router.beforeEach((to, from, next) => {
  const userStore = useUserStore()
  
  if (to.meta.requiresAuth && !userStore.isLoggedIn) {
    next('/login') // 未登录则重定向
  } else {
    next()
  }
})

export default router
```


### 4.2 在 API 服务中使用 &#x20;

```typescript 
// services/auth.ts
import { useUserStore } from '../store/user'

export function login(username: string, password: string) {
  const userStore = useUserStore()
  
  return fetch('/api/login', {
    method: 'POST',
    body: JSON.stringify({ username, password })
  }).then(res => {
    if (res.ok) {
      return res.json().then(userData => {
        userStore.setUser(userData) // 更新 Store 状态
        return userData
      })
    } else {
      throw new Error('登录失败')
    }
  })
}
```


### 4.3 在自定义插件中使用 &#x20;

```typescript 
// plugins/autoSave.ts
import { App } from 'vue'
import { useSettingsStore } from '../store/settings'

export function createAutoSavePlugin() {
  return {
    install(app: App) {
      const settingsStore = useSettingsStore()
      
      // 监听窗口关闭事件，保存设置
      window.addEventListener('beforeunload', () => {
        settingsStore.saveToLocalStorage()
      })
    }
  }
}
```


### 注意事项 &#x20;

- 在组件外使用 Store 时，需确保 Pinia 已被正确初始化（如在 Vue 3 中通过 `createPinia()` 注册）。 &#x20;
- 避免在全局作用域中直接引用 Store 实例（如 `const store = useCounterStore()`），建议在函数内部动态获取，以保证响应式特性正常工作。
