# 3.LLM简介

## 1. 大模型介绍

### 1.1 简介

大模型（Large Language Model）是一种特殊的人工智能技术，其显著特征是拥有庞大的参数规模，通常包含数十亿甚至上百亿个参数。这些参数如同模型的“大脑”，赋予了大模型理解和处理复杂信息的强大能力。大模型在自然语言处理、生成、理解等多个领域展现出广泛的应用前景，能够完成文本生成、翻译、问答、摘要等多种任务，是当前人工智能领域的研究热点和发展重点。

### 1.2 工作原理

一个大型语言模型（LLM）主要由两个关键部分组成：

- 一个包含数十亿个参数的大型文件，这是神经网络模型的核心，承载着模型对知识的存储和表示。
- 一个只有几百行代码的小文件，用于运行该模型，实现对模型的调用和操作。

可以将LLM形象地理解为一个“下一个词预测器”或者高级的自动补全功能。它基于已有的文本序列，通过对大量数据的学习，预测出最有可能接下来出现的词语，从而生成连贯的文本内容。这种工作方式使得大模型能够根据输入的上下文，生成符合逻辑和语义的响应。

### 1.3 训练过程

大模型的训练过程主要包括预训练和微调两个阶段：

- **第一阶段：预训练**
  - 预训练的目标是将互联网内容压缩到一个神经网络中。
  - 具体步骤如下：
    1. 从互联网上获取海量的文本数据，例如10TB的文本。
    2. 借助GPU等强大的计算设备，并投入数百万美元的计算资源，对这些文本进行处理，将其压缩到一个神经网络中。
    3. 通过这一过程，获得基础模型。
  - 其中，神经网络就像一个神经元网络，神经元之间相互传递信息并做出决策。随着处理数据的增多，神经元能够不断改善决策能力，从而使模型更好地理解和处理文本信息。
- **第二阶段：微调**
  - 微调的目的是针对特定用例对基础模型进行优化。
  - 具体操作如下：
    1. 使用由人类撰写的10万个以上的对话来训练模型，或者根据一系列问题，让人类审查并选择模型的最佳答案。
    2. 经过训练后，获得微调后的模型。
    3. 运行评估来进一步完善模型，找出模型响应中存在的问题，并让人类进行修正，以提高模型在特定任务上的表现。

## 2. Qwen大模型实践（OpenAI格式）

### 2.1 OpenAI格式介绍（Node.js）

- **三种使用方式**：使用Qwen大模型有三种方式，分别是DashScope SDK（目前支持Java和Python两种语言）、HTTP接口调用以及兼容OpenAI SDK。
- **安装OpenAI Node.js SDK**：可以通过访问[https://github.com/openai/openai-node](https://github.com/openai/openai-node "https://github.com/openai/openai-node")来获取相关信息并进行安装。
- **API key相关操作**：
  - 查看API Key的地址为 [大模型服务平台百炼控制台](https://bailian.console.aliyun.com/?tab=model#/api-key "大模型服务平台百炼控制台")
  - 在代码中可以使用[https://www.npmjs.com/package/dotenv](https://www.npmjs.com/package/dotenv "https://www.npmjs.com/package/dotenv") 来获取环境变量中的API key。
- **初始化OpenAI类**：示例代码如下：

```javascript 
// OpenAI 兼容接口详情 https://help.aliyun.com/zh/dashscope/developer-reference/compatibility-of-openai-with-dashscope
const client = new OpenAI({
  apiKey: process.env['ALI_API_KEY'], 
  // 注意要修改为兼容的 base url
  baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1'
});
```


### 2.2 阿里云百炼简介

阿里云百炼是为用户提供访问和利用LLM的平台或服务的实体。它除了提供模型本身的API/SDK外，还具有以下特点：

- 提供了预置应用模板，如检索增强、AI妙笔等。
- 提供了预置业务场景模型，如摘要模型、行业模型等。
- 拥有可视化的操作控制台页面，方便用户进行操作。
- 提供了一系列大模型应用搭建的可视化工具，降低了用户开发和应用大模型的门槛。

### 2.3 语言模型示例

```javascript 
// 安装依赖：npm install openai dotenv
import 'dotenv/config'
import OpenAI from 'openai';
import fs from 'fs'
async function callQwenTurbo() {
  try {
    // 初始化OpenAI客户端（兼容Qwen模型）
    const client = new OpenAI({
      apiKey: process.env['LLM_API_KEY'],
        baseURL: process.env['LLM_BASE_URL']
    });

    const model_name : string = process.env['LLM_MODEL_NAME'] || "qwen-max"
    // console.log(`model_name: ${model_name}`)
    // console.log(`LLM_API_KEY: ${process.env['LLM_API_KEY']}`)
    // console.log(`LLM_BASE_URL: ${process.env['LLM_BASE_URL']}`)

    // 调用语言模型（以文本生成为例）
    const response = await client.chat.completions.create({
      model: model_name,
      messages: [
        {
          role: "user",
          content: "请用一句话描述人工智能的发展趋势"
        }
      ],
      temperature: 0.7, // 控制输出随机性，0-1之间
      max_tokens: 100 // 最大生成token数
    });

    // 输出结果
    console.log("模型响应：", response.choices[0].message.content);
    
  } catch (error) {
    console.error("调用失败：", error);
    if (error.response) {
      console.error("状态码：", error.response.status);
      console.error("错误信息：", error.response.data);
    }
  }
}

// 执行调用
callQwenTurbo();
```

### 2.5 长文本模型示例

- **qwen-long模型**：它是通义千问模型家族中具备强大长文本处理能力的模型，最大可支持千万tokens的对话窗口，并通过与OpenAI兼容的模式提供API服务（Dashscope SDK调用方式仍然兼容）。
- **文件上传接口**：DashScope提供了文件上传接口，帮助用户将文件上传到临时存储空间，以便更安全地使用文件输入相关的API调用。具体接口信息可参考[https://help.aliyun.com/zh/model-studio/developer-reference/document-upload-openai-qwen-long](https://help.aliyun.com/zh/model-studio/developer-reference/document-upload-openai-qwen-long "https://help.aliyun.com/zh/model-studio/developer-reference/document-upload-openai-qwen-long")。通过该接口，用户可以将长文本文件上传，然后调用qwen-long模型对文件内容进行分析、摘要等操作

```typescript 
async function callQwenLong() {
  try {
    // 初始化OpenAI客户端（兼容Qwen模型）
    const client = new OpenAI({
      apiKey: process.env['LLM_API_KEY'],
        baseURL: process.env['LLM_BASE_URL']
    });
    // qwen-long
```
