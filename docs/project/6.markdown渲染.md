# 6.渲染Markdown

## 1. markdown-it &#x20;

### 1.1 简介 &#x20;

**markdown-it** 是一个将 Markdown 解析为 HTML 的高效解析器，遵循 CommonMark 规范，同时具备以下特点： &#x20;

- **语法扩展**：支持自动链接 URL、排版美化等增强功能。 &#x20;
- **模块化设计**：易于扩展，可自定义插件或使用社区插件（如 `markdown-it-anchor`、`markdown-it-highlightjs` 等）。 &#x20;
- **高性能**：适合处理大量 Markdown 文本，解析速度快。 &#x20;

官网/仓库：[https://github.com/markdown-it/markdown-it](https://github.com/markdown-it/markdown-it "https://github.com/markdown-it/markdown-it") &#x20;

### 1.2 使用 &#x20;

#### 基础用法 &#x20;

```javascript 
import markdownit from 'markdown-it'  
const md = markdownit()  
const result = md.render('# markdown-it rulezz!')  
// 输出：<h1>markdown-it rulezz!</h1>
```


#### 插件使用 &#x20;

```javascript 
// 引入插件（示例）
import plugin1 from 'markdown-it-plugin1'
import plugin2 from 'markdown-it-plugin2'

const md = markdownit()  
  .use(plugin1)  // 无参数插件
  .use(plugin2, { option: 'value' })  // 带参数插件
  .use(plugin3);
```


插件列表：[https://www.npmjs.com/search?q=keywords:markdown-it-plugin](https://www.npmjs.com/search?q=keywords:markdown-it-plugin "https://www.npmjs.com/search?q=keywords:markdown-it-plugin") &#x20;

### 1.3 Vue Markdown renderer &#x20;

**简介**：基于 markdown-it 的 Vue 封装库，轻量级且支持 TypeScript。 &#x20;

仓库：[https://github.com/cloudacy/vue-markdown-render](https://github.com/cloudacy/vue-markdown-render "https://github.com/cloudacy/vue-markdown-render") &#x20;

安装：`npm install vue-markdown-render --save` &#x20;

#### 示例代码 &#x20;

```html 
<template>
  <vue-markdown :source="markdown" :plugins="plugins" />
</template>

<script setup>
import VueMarkdown from 'vue-markdown-render'
import MarkdownItAnchor from 'markdown-it-anchor'

const markdown = '# 标题\n这是一段 Markdown 内容'
const plugins = [MarkdownItAnchor]  // 注册插件
</script>
```


## 2. Tailwind CSS Typography 插件 &#x20;

### 2.1 插件简介 &#x20;

**为什么需要它？** &#x20;

Tailwind CSS 默认对 HTML 元素应用强重置样式（reset），导致富文本（如 Markdown 渲染的 HTML）失去默认排版（标题、段落等样式统一）。 &#x20;

**插件作用**： &#x20;

- 为标题、段落、列表、引用等元素重新添加合理的默认样式。 &#x20;
- 支持响应式设计、主题定制、暗模式，只需在容器添加 `prose` 类即可应用样式。 &#x20;

**特点**： &#x20;

- 默认样式规范，适配多种设备。 &#x20;
- 支持元素修饰符（如 `prose-xl`、`prose-invert`）。 &#x20;

演示地址：[https://play.tailwindcss.com/uj1vGACRJA?layout=preview](https://play.tailwindcss.com/uj1vGACRJA?layout=preview "https://play.tailwindcss.com/uj1vGACRJA?layout=preview") &#x20;

### 2.2 安装使用 &#x20;

#### 安装 &#x20;

```bash 
npm install -D @tailwindcss/typography
```


#### 配置（Tailwind 配置文件） &#x20;

```javascript 
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      // 可自定义主题样式
      typography: {
        DEFAULT: {
          css: {
            color: '#333',
            h1: { 'font-size': '2rem' },
            // 更多样式...
          },
        },
      },
    },
  },
  plugins: [
    require('@tailwindcss/typography'),
  ],
}
```


#### 使用示例 &#x20;

```html 
<div class="prose max-w-2xl mx-auto">
  <h1>标题</h1>
  <p>这是一段应用了 Typography 样式的文本。</p>
  <ul>
    <li>列表项 1</li>
    <li>列表项 2</li>
  </ul>
</div>
```


## 3. Highlight.js 语法高亮 &#x20;

### 3.1 简介 &#x20;

**Highlight.js** 是用于代码语法高亮的轻量级库，具备以下特性： &#x20;

- **多语言支持**：支持超过 192 种编程语言（如 JavaScript、Python、Java 等）和数据格式（JSON、XML 等）。 &#x20;
- **自动检测语言**：无需手动指定代码块语言，自动识别。 &#x20;
- **丰富主题**：提供 40+ 种样式主题（如 `github`、`dracula`、`monokai` 等）。 &#x20;
- **轻量易集成**：体积小，可通过 CDN 或 npm 快速引入。 &#x20;

官网/仓库： &#x20;

- [https://highlightjs.org/](https://highlightjs.org/ "https://highlightjs.org/") &#x20;
- [https://github.com/highlightjs/highlight.js](https://github.com/highlightjs/highlight.js "https://github.com/highlightjs/highlight.js") &#x20;

示例演示：[https://highlightjs.org/examples/](https://highlightjs.org/examples/ "https://highlightjs.org/examples/") &#x20;

### 3.2 使用 &#x20;

#### 方式一：直接引入（非 Vue 项目） &#x20;

1. 引入脚本和样式（以 CDN 为例）： &#x20;

```html 
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/highlight.js@11.7.0/styles/github.min.css">
<script src="https://cdn.jsdelivr.net/npm/highlight.js@11.7.0/lib/core.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/highlight.js@11.7.0/lib/languages/javascript.min.js"></script> <!-- 按需引入语言 -->
```


1. 应用高亮（自动检测）： &#x20;

```html 
<pre><code class="language-javascript">
function highlightDemo() {
  console.log('语法高亮示例');
}
</code></pre>

<script>
  hljs.highlightAll(); // 自动高亮页面所有代码块
</script>
```


#### 方式二：与 markdown-it 集成 &#x20;

1. 安装插件： &#x20;

```bash 
npm install markdown-it-highlightjs --save
```


1. 配置 markdown-it： &#x20;

```javascript 
import markdownit from 'markdown-it'
import markdownitHighlightjs from 'markdown-it-highlightjs'

const md = markdownit()
  .use(markdownitHighlightjs)  // 注册高亮插件

// 渲染包含代码块的 Markdown
const result = md.render('```javascript\nconsole.log("高亮代码");\n```')
```


**说明**：插件会自动将 Markdown 代码块转换为带高亮类的 HTML，需额外引入 Highlight.js 的 CSS 主题文件。
