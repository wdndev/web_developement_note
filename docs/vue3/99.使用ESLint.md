# 99.使用 ESLint

## 1.简介

- [ESLint官网](https://eslint.org/ "ESLint官网")

开源JavaScript/TypeScript代码检查工具，通过解析代码生成AST（抽象语法树）进行静态分析。

规范的代码格式能提升团队协作效率和开发体验。


无规范可能引发的问题：


- 代码可读性差

- 提交时格式修改占用不必要时间

## 2.基础使用

### 2.1 命令行工具

```javascript 
npm install eslint --save-dev
npx eslint --version
```


### 2.2 生成配置文件

- 自动生成配置文件

```markdown 
npm init @eslint/config
# 按提示选择配置
```


### 2.3 Rules 规则系统

[完整规则列表](https://eslint.org/docs/latest/rules/ "完整规则列表")


规则级别：

- `0`/`off`: 关闭
- `1`/`warn`: 警告
- `2`/`error`: 错误

```markdown 
// 示例配置
rules: {
  'semi': 2 // 强制分号
}
```


## 3.编辑器集成（VSCode）

vscode 默认只会验证 `.js` 文件，这里我们添加后缀让它验证更多的文件格式。

`.vscode/settings.json`

```json 
{
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    "vue",
    "typescript",
    "typescriptreact"
  ]
}
```


## 4.Extends 扩展配置

一系列的规则作为一组。大家可以把这一组拿来用到自己的项目中，那么这个就是 extends 字段，是一个数组，里面是几个项目，其实在 extends 中的每一个字段，都是一组规则。

扩展规则组简化配置：

```javascript 
"extends": "eslint:recommended"  // 使用官方推荐规则组
```


- [Rules Reference - ESLint - Pluggable JavaScript Linter](https://eslint.org/docs/latest/rules/ "Rules Reference - ESLint - Pluggable JavaScript Linter")：里面有绿色勾的就是启用的设置。

## 5.Vite 集成

- [vite-plugin-eslint - npm](https://www.npmjs.com/package/vite-plugin-eslint "vite-plugin-eslint - npm")

安装插件：

```bash 
npm install eslint vite-plugin-eslint --save-dev
# or
yarn add eslint vite-plugin-eslint -D
```


`vite.config.ts`：

```javascript 
import eslint from 'vite-plugin-eslint'
export default defineConfig({
  plugins: [eslint()]
})
```


## 6.Vue/TS 支持

- [Introduction | eslint-plugin-vue](https://eslint.vuejs.org/ "Introduction | eslint-plugin-vue")

### 6.1 Vue 支持

安装ESLint插件：

```markdown 
npm install eslint-plugin-vue --save-dev
```


所有的规则列表：[Available rules | eslint-plugin-vue](https://eslint.vuejs.org/rules/ "Available rules | eslint-plugin-vue")

配置扩展（三组强度可选）：

```yaml 
extends: [
  "plugin:vue/vue3-essential",      // 基础规则
  // "plugin:vue/vue3-strongly-recommended",  // 严格规则
  // "plugin:vue/vue3-recommended"   // 最严格规则
]
```


### 6.2 TypeScript 支持

> 目前还没法验证 Typescript 的语法，一些符号会报错，比如泛型的括号。>

安装配置包：

```bash 
npm install @vue/eslint-config-typescript --save-dev
```


> 其实是 [https://typescript-eslint.io/rules/](https://typescript-eslint.io/rules/ "https://typescript-eslint.io/rules/") 一个Vue 的特供版本。

完整配置：

```typescript 
extends: [
  "plugin:vue/vue3-essential", 
  "@vue/eslint-config-typescript"  // TS支持
]
```
